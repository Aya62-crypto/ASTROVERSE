ASTROVERSE — starter website project
=====================================

FILES
- index.html : website structure and page content
- style.css  : responsive visual design
- app.js     : planet selector, mystery cards, NASA image gallery and Astrobot demo

HOW TO OPEN
1. Extract the ZIP file.
2. Open the astroverse_project folder.
3. Double-click index.html to preview it in your browser.
4. An internet connection is needed for Google Fonts and the live NASA image gallery.

HOW TO PUBLISH WITH GITHUB PAGES
1. Open your GitHub repository.
2. Upload index.html, style.css and app.js (and this README if you want).
3. Make sure index.html is in the repository's main/root folder.
4. Go to Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose your main branch and / (root), then Save.
7. Wait for GitHub Pages to publish the site.

IMPORTANT SCIENCE / SOURCE NOTES
- Planet stats are rounded educational values. Some values, especially moon counts, can change as new moons are confirmed.
- NASA gallery images are fetched from NASA's public Images and Videos Library API (images-api.nasa.gov). The gallery may need an internet connection and may occasionally fail to load.
- Always open the original NASA item and check its credit/usage notes before reusing an image elsewhere.
- Astrobot in this starter project is a rule-based demo chatbot. It is NOT connected to a live AI model. A real AI chatbot needs a secure backend/server so a secret API key is never exposed in public website JavaScript.
- The Big Bang is the leading scientific model for the evolution of the universe. Multiverse ideas and some other concepts are speculative, not confirmed facts.
